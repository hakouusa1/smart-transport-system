# Plan: Fix Bus Not Showing on Map in voyageur_app

## Problem Statement
The bus does not show in the map on the voyageur_app.

## System Architecture

### Data Flow:
1. **chauffeur_app** (Driver): 
   - Driver must have a bus assigned (driverId matches user UID in Firestore)
   - Driver goes "online" → status = "online" in Firestore
   - Driver starts trip → status = "on_trip" in Firestore
   - `LocationService.startTracking(busId)` writes GPS to RTDB at `locations/<busId>`

2. **voyageur_app** (Passenger):
   - `getActiveBuses()` fetches buses where isActive == true from Firestore
   - Listens to RTDB at `locations/<busId>` for live location
   - Shows bus marker ONLY if location data exists and is valid
   - Shows departure/arrival markers + "Aucun bus en trajet" message if no location

### Key Files:
- `voyageur_app/lib/screens/map_screen.dart` - Main single-bus tracking view
- `voyageur_app/lib/screens/all_buses_map_screen.dart` - Shows all active buses
- `voyageur_app/lib/services/location_service.dart` - Location stream from RTDB
- `voyageur_app/lib/services/bus_service.dart` - Bus data from Firestore

## Root Cause Analysis

The bus shows on map ONLY when:
1. ✅ Bus is active (isActive == true in Firestore)
2. ✅ Driver status is "on_trip" (trip started in chauffeur_app)
3. ✅ Location data is being written to RTDB at `locations/<busId>`

**The most likely cause**: The driver has NOT started a trip yet. The code at line 399 in `all_buses_map_screen.dart` shows "Aucun bus en trajet actuellement" when no location data exists.

## Investigation Steps:

1. **Verify in Firebase Console**:
   - Check Firestore: `buses` collection → verify bus has isActive=true
   - Check Firestore: bus.driverStatus should be "on_trip" (not "offline" or "online")
   - Check RTDB: `locations/<busId>` path should have location data

2. **Driver App (chauffeur_app)**:
   - Verify driver is logged in and has a bus assigned
   - Verify driver clicked "Démarrer le trajet" button
   - Check if location is being written to RTDB

3. **Passenger App (voyageur_app)**:
   - Check which bus is being passed to MapScreen
   - Verify the busId matches the one in RTDB

## Proposed Fix Implementation:

### If issue is "driver hasn't started trip":
- This is working as designed - bus only shows when trip is active
- Add clearer UI message indicating this

### If issue is "location not being written":
- Check chauffeur_app GPS tracking is active
- Verify Firebase RTDB is properly configured

### Add fallback for static display:
- Even without live location, show bus at departure/arrival
- This is already partially implemented
