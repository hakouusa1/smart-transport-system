# Fix: Straight line from bus position to route start

## Problem

When the bus is **before the departure point** (hasn't reached the start of the route yet), the `_splitRoute()` method in all tracking screens draws a **straight line** from the bus's current GPS position directly to the closest route point (which is the departure/start). This looks wrong because it doesn't follow roads.

### Root Cause

In `_splitRoute()` (present in all 3 apps), the done route is built as:

```dart
_doneRoute = [..._fullRoute.sublist(0, idx + 1), _busLocation!.latLng];
```

When `idx == 0` (bus is before the start), this creates:
```
[departure_point, bus_current_position]
```

This is a **straight line** — not a road-following route. The same issue affects `_leftRoute`:
```
[bus_current_position, ...all_route_points]
```

## Solution

When the bus is before the route start (closest point is the departure or near it), we need to get a proper road-following route from the bus's current position to the departure point. Two approaches:

### Option A: Fetch a "pre-route" from bus to departure (Recommended)

When `idx == 0` (or the bus is more than ~50m from the closest route point), call Mapbox Directions API to get a real route from `_busLocation` to the departure point, and prepend those points to `_doneRoute`.

**Pros:** Shows the actual road path the bus would take to reach the start.
**Cons:** Extra API call.

### Option B: Don't draw done route when bus is before start

Simply skip the `_doneRoute` polyline when `idx == 0`, and only draw the `_leftRoute` from the departure point (not from the bus). This avoids the straight line entirely.

**Pros:** No extra API call, clean behavior.
**Cons:** The bus appears disconnected from the route until it reaches the start.

### Option C: Use Mapbox API for the "bus to route" segment

Similar to Option A but more targeted — only fetch the road route when the bus is significantly far (>100m) from the closest route point. When close, keep the current straight-line behavior (acceptable when the bus is essentially on the route).

**Pros:** Best visual result, only calls API when needed.
**Cons:** Slightly more complex logic.

## Recommended Approach: Option C

This is the best balance. Here's the implementation plan:

### 1. `voyageur_app/lib/screens/map_screen.dart`

- Add a `_preRoute` field (`List<LatLng>`) for the path from bus to route start
- In `_splitRoute()`: detect when `idx == 0` and bus is >100m from `_fullRoute[0]`
- Fetch route from `_busLocation!.latLng` to `_fullRoute[0]` via `RouteService.getRoute()`
- Store in `_preRoute` and render as a thin grey line before the done route
- When bus reaches the route (`idx > 0` or distance < 100m), clear `_preRoute`

### 2. `chauffeur_app/lib/screens/driver_dashboard_screen.dart`

- Same logic: add `_preRoute` field
- In `_splitRoute()`: detect before-start condition
- Fetch route inline via Mapbox API
- Render as thin orange line

### 3. `chauffeur_app/lib/screens/map_screen.dart`

- Same pattern as above

### 4. `transport_app/lib/screens/bus_tracking_screen.dart`

- Same pattern: add `_preRoute` field
- Use `RouteService.getRoute()` for the pre-route
- Render as thin green/grey line

## Implementation Details

### Modified `_splitRoute()` pattern (all apps):

```dart
void _splitRoute() {
  if (!_routeOk || _fullRoute.isEmpty || _busLocation == null) return;
  double min = double.infinity; int idx = 0; const d = Distance();
  for (int i = 0; i < _fullRoute.length; i++) {
    final v = d.as(LengthUnit.Meter, _busLocation!.latLng, _fullRoute[i]);
    if (v < min) { min = v; idx = i; }
  }

  // If bus is before route start and far away, get a real route to the start
  if (idx == 0 && min > 100) {
    _loadPreRoute(_busLocation!.latLng, _fullRoute[0]);
  } else {
    _preRoute = [];
  }

  setState(() {
    _doneRoute = [..._fullRoute.sublist(0, idx + 1), _busLocation!.latLng];
    _leftRoute = [_busLocation!.latLng, ..._fullRoute.sublist(idx)];
  });
}
```

### New `_loadPreRoute()` method:

```dart
Future<void> _loadPreRoute(LatLng from, LatLng to) async {
  final r = await RouteService.getRoute(from, to);
  if (mounted && r != null && r.points.isNotEmpty) {
    setState(() => _preRoute = r.points);
  }
}
```

### Polyline rendering (add before done route):

```dart
// Pre-route: bus to departure (when before start)
if (_preRoute.length >= 2)
  PolylineLayer(polylines: [
    Polyline(points: _preRoute, color: Colors.grey.withValues(alpha: 0.5), strokeWidth: 6),
  ]),
```
