# Plan: Add Button Click Animations in Voyageur App Map Screens

## Overview

Add smooth scale bounce animations to the floating control buttons (Fit All, Follow Bus, My Location) in the map screens of the `voyageur_app`. This provides visual feedback when users tap these buttons.

## Affected Files

1. `voyageur_app/lib/screens/map_screen.dart` - Single bus tracking map
2. `voyageur_app/lib/screens/all_buses_map_screen.dart` - All buses overview map

## Current State

- Both map screens have a `_Btn` widget class that renders circular floating buttons
- The `_Btn` widget uses `InkWell` for tap handling but has no animation on tap
- An existing `SmoothMarker` widget in `animated_marker.dart` demonstrates the pattern for position-based animations using `AnimationController`

## Implementation Plan

### Step 1: Create Animated Button Widget

Create a new reusable `AnimatedIconButton` widget that wraps an icon button with a smooth scale bounce animation:

- Use `AnimationController` with `vsync` for the animation
- Use `Tween<double>` from 1.0 to 0.85 and back (scale down then bounce up)
- Apply `CurvedAnimation` with `Curves.elasticOut` for the spring effect
- Duration: ~200ms for a snappy feel
- Wrap the button content in a `ScaleTransition`
- Keep the existing `InkWell` for the ripple effect

### Step 2: Replace `_Btn` in `map_screen.dart`

In `map_screen.dart`, replace the `_Btn` widget (lines 575-584) with the new animated version:

- Convert `_Btn` from `StatelessWidget` to `StatefulWidget`
- Add an `AnimationController` in the state
- Trigger the animation on tap via `_controller.forward().then((_) => _controller.reverse())`
- Wrap the `Icon` in a `ScaleTransition` using the animation
- Dispose the controller in `dispose()`

### Step 3: Replace `_GBtn` in `all_buses_map_screen.dart`

In `all_buses_map_screen.dart`, apply the same changes to the `_GBtn` widget (lines 537-545):

- Convert `_GBtn` from `StatelessWidget` to `StatefulWidget`
- Add animation controller and scale transition
- Trigger animation on tap

### Step 4: Verify Consistency

Ensure both screens have consistent animation behavior:
- Same duration (200ms)
- Same scale factor (0.85)
- Same curve (elasticOut or easeOutBack)

## Technical Details

### Animation Parameters
- **Duration**: 200 milliseconds
- **Scale range**: 1.0 → 0.85 → 1.0
- **Curve**: `Curves.easeOutBack` (subtle bounce) or `Curves.elasticOut` (more pronounced spring)
- **Trigger**: On tap, before executing the button's action

### Widget Structure (per button)
```
StatefulWidget (_Btn / _GBtn)
  └─ State
      ├─ AnimationController (200ms)
      └─ build()
          └─ Material (circle, elevation)
              └─ InkWell (ripple, onTap)
                  └─ Padding
                      └─ ScaleTransition (animation)
                          └─ Icon
```

### Code Changes Summary

**map_screen.dart `_Btn` class:**
- Add `with SingleTickerProviderStateMixin` to state
- Add `late AnimationController _animController`
- Add `late Animation<double> _scaleAnimation`
- In `initState`: create controller with 200ms duration, create curved animation
- In `onTap`: call `_animController.forward().then((_) => _animController.reverse())` then call original `onTap`
- In `build`: wrap `Icon` with `ScaleTransition`
- In `dispose`: dispose controller

**all_buses_map_screen.dart `_GBtn` class:**
- Same changes as above

## Testing

Since this is a UI animation change, testing is manual:
1. Run the app on a device/emulator
2. Navigate to a bus map screen
3. Tap each floating button (Fit All, Follow Bus, My Location)
4. Verify the button scales down and bounces back smoothly
5. Verify the button's action still executes correctly after animation

## Notes

- The existing `SmoothMarker` widget in `widgets/animated_marker.dart` is not used in the current codebase and is unrelated to button animations
- No changes needed to the map itself or the button functionality
- Animation is purely visual feedback; button actions remain unchanged
